# QR Hayot 🆘

An Android app that turns a person's emergency information into a QR code.
If someone has a seizure, a sugar drop, or an asthma or allergy attack in public,
people nearby can scan the code with any phone camera, with no app and no internet,
and see how to help, what not to do, and who to call.

## Features
- **Emergency QR code** with the person's condition, step-by-step first aid, medicines, allergies, blood type and family contacts
- **Lock-screen mode**, so the QR can be scanned without unlocking the phone
- **Ready-made first aid templates** (epilepsy, diabetes, asthma, severe allergy, heart condition, fainting, autism) plus the user's own tips
- **SOS message** that texts both contacts with the user's location
- **Help tools:** seizure timer, CPR rhythm beeper, attention siren, nearest hospital
- **Uzbek and English** interface, with both languages in the QR text
- **Privacy first:** data is stored only on the phone, with no account and no server

## Built with
Kotlin · Jetpack Compose · Navigation Compose · ConstraintLayout · ZXing

## Disclaimer
QR Hayot stores information and shows general first aid guidance. It is not a medical
device and does not replace professional care. First aid texts should be reviewed by a
medical professional before real use.
